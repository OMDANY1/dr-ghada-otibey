# الموقع التعريفي الرسمي — الدكتورة غادة العتيبي | Dr. Ghada Alotaibi

موقع تعريفي ثنائي اللغة (العربية الفصحى والإنجليزية) بتصميم تحريري معاصر، مخصص للدكتورة غادة العتيبي — استشارية أمراض جلدية في مدينة الرياض.

## المزايا والصفحات المنفذة

- **تعدد اللغات الكامل (`/ar` و`/en`)**: دعم كامل لاتجاهي `RTL` و`LTR` مع الحفاظ على المسار المكافئ عند التبديل.
- **نظام خطوط عصري موحد**: خط `IBM Plex Sans Arabic` للعربية، وخط `Avenir Next / Avenir` مع بديل `Manrope` للإنجليزية.
- **خريطة موقع متكاملة**:
  - الرئيسية (`/[lang]`)
  - اعرف الدكتورة (`/[lang]/about`)
  - مجالات العناية (`/[lang]/areas-of-care`)
  - المقالات مع البحث والتصنيفات (`/[lang]/articles` و`/[lang]/articles/[slug]`)
  - المراجعات (`/[lang]/reviews`)
  - الحجز والاستشارة من 3 خطوات + الأسئلة الشائعة (`/[lang]/consultation`)
  - سياسة الخصوصية (`/[lang]/privacy`)
- **التنسيق عبر واتساب بخصوصية تامة**: معالجة محلية لمدخلات النموذج دون تخزين في قواعد بيانات أو `localStorage`، مع موافقة صريحة وتمرير النص المرمز إلى واتساب التنسيق.
- **توثيق المصادر**: سجل فصل الحقائق المؤكدة عن البيانات المؤجلة في `docs/DATA_SOURCES_AND_VERIFICATION.md`.

## التشغيل المحلي (Local Development)

```bash
npm install
npm run dev
```

لبناء نسخة الإنتاج وتشغيلها:

```bash
npm run build
npm run start
```

## متغيرات البيئة عند النشر (Production)

يمكن ضبط نطاق الإنتاج الرسمي لتوليد روابط `canonical` و`hreflang` وملف `sitemap.xml` تلقائيًا:

```env
NEXT_PUBLIC_SITE_URL=https://your-production-domain.com
```
